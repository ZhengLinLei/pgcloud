# tools/

Utilities that run **outside** the PgCloud containers, on an operator's machine or server.

| Folder | Description |
|---|---|
| [`dashboard/`](dashboard/) | Terminal dashboards to monitor the PostgreSQL nodes (status, replication lag, raw stats). |
| [`pgcloud-launcher/`](pgcloud-launcher/) | Web app (Docker image) to design the cluster visually, deploy it to your servers over SSH and monitor it in real time. |
| [`book/`](book/) | Builder of the PgCloud book (`docs/wiki/PgCloud_The_Master_Book.pdf`): chapter 7 sources, screenshots and the assembly script. |
